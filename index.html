Crossbill Wallet

A wallet for Bitcoin (XBT) on the BLAKE2b chain that runs on your own StartOS server, holds no seed words, and has every send signed on your Krux.

The BLAKE2b chain is the one that changed Bitcoin's proof of work to BLAKE2b and signs with the unified opt-in signature hash (0x21). Crossbill is open source under Apache 2.0 and not audited. There is also an iPhone app with the same screens.

How it works

You open Crossbill in a browser on a computer or a phone. Crossbill runs on your StartOS server and uses your own Bitcoin Knots node: wallets live in the node's cormorant watch-only wallet, the same one the iPhone app and desktop Shrike use, so an existing wallet opens with no rescan. The server never holds seed words. Every send goes to your Krux to be signed, by QR code or microSD.

What you need

  • StartOS 0.4.0 or later.
  • Bitcoin Knots on the BLAKE2b chain, installed from this registry:
    https://start9.mempool.guide
    Crossbill refuses a node on another chain.
  • A Krux with Paperclip's firmware. Paperclip's K210 Krux Hardware Wallet with Paperclip's BLAKE2b firmware. Standard Krux firmware refuses unified signatures.
  • Optional: Lightning Fork, for Lightning balances, activity, invoices and payments.

Install in six steps

  1. Add the Finchly6819 registry

    In StartOS, open the Marketplace, click the registry name at the top left, then + Add, and enter:

    https://start9.crossbillwallet.com

  2. Install Crossbill

    Switch to the Finchly6819 registry and install Crossbill.

  3. Run the setup tasks

    Run Set Password on Crossbill and copy the password into your password manager. It is shown only once. If StartOS also asks you to run Auto-Configure on Bitcoin, run it: it turns on the node's wallet, which Crossbill keeps its watch-only wallets in.

  4. Start Crossbill and sign in

    Start Crossbill, open its Web UI at its https:// address, and sign in with the password. The camera only works on an https:// address, or on an onion address in Tor Browser.

  5. Add your Krux wallet

    On the Krux, show its key's QR code. In Crossbill, choose Scan the Krux's key and hold the code up to the camera. Or save the key to microSD and choose Open the key file from microSD. Check the balance and the first receive address match what you expect.

  6. Try a small send

    Build a send for a small amount and sign it on your Krux, as shown below.

Lightning, if you run Lightning Fork: in its dashboard, open Mobile app, then Pair a phone. In Crossbill, open Settings, Node and Lightning, Lightning, and choose Scan. The code works once, for five minutes. Payments stay off until you run Turn On Lightning Payments on Crossbill in StartOS.

StartOS or iPhone?

Both share the same screens and the same cormorant wallet on your node, so you can use both.

Good to know

Watch-only
There is no screen for seed words, and the server refuses to store them. Wallets come from a Krux's key, and every send is signed on the Krux.
Not audited
Use it at your own risk, under the Apache 2.0 terms. Start with a small amount.
Two-factor on the server
You can turn two-factor on in Crossbill's Settings, and it asks for the code before sends. On the server the page checks the code, and anyone signed in can read its key. It guards against a slip, not against someone who has the password. Guard the password itself. Once Lightning payments are on, anyone who can sign in can pay.
The XBT price
The only outside service the server contacts is Neoxa Exchange's public API, for the live XBT price, through Tor when Tor is installed on your server and the page asks for it. Everything else goes to your own nodes.
Backups
A StartOS backup of Crossbill brings back the password, two-factor, the Lightning Fork pairing, and every wallet's public data, labels and contacts. The node's cormorant wallet is Bitcoin's data, not Crossbill's, so it is in Bitcoin's backup instead. A restored Lightning pairing works only while Lightning Fork still lists it.
Current limits
  • No sign-out button in the page. Running Set Password signs out every session.
  • Mainnet only.
  • Paperclip's Krux is the only hardware wallet.
  • Untested on a pruned node.
  • No notifications or widgets. Those are part of the iPhone app.
